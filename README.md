# Web Scraping & SQL ETL Pipeline: Bookstore Analytics

## 📌 Project Overview
This project is an end-to-end **ETL (Extract, Transform, Load)** data pipeline. I built a Python-based web scraper to extract product data from an online bookstore, cleaned the raw text using Pandas, and loaded the structured data into a local SQLite database. Finally, I used SQL to query the database and extract actionable business insights regarding pricing and product ratings.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Data Extraction (Web Scraping):** `requests`, `BeautifulSoup4`
* **Data Transformation (Cleaning):** `pandas`
* **Database & Querying (Load & Analyze):** `sqlite3`, SQL

## ⚙️ The ETL Pipeline Architecture
1. **Extract:** Built a web scraper to parse HTML from [Books to Scrape](https://books.toscrape.com/), successfully navigating DOM elements to extract Book Titles, Raw Prices, and String-based Star Ratings.
2. **Transform:** Passed the raw data into a Pandas DataFrame to handle character encoding errors (programmatically removing `Â£` symbols), cast text strings to `float` numeric types, and mapped categorical text ratings (e.g., "Three") to numerical integers (`3`).
3. **Load:** Established a connection to a local SQLite database and injected the cleaned DataFrame into a structured `books` table for persistent storage and querying.

## 📊 Key SQL Insights
After building the database, I wrote SQL queries to act as a Category Manager and uncovered the following insights:
* **Price vs. Quality:** Aggregated the average price of books grouped by their star rating to determine if higher-rated books commanded a market premium.
* **Value Identifiers:** Filtered the database to identify "High Value" targets—specifically isolating books with a perfect 5-star rating priced under £20.
* **Inventory Valuation:** Calculated summary statistics, including total inventory counts, maximum/minimum prices, and the total capital value of the scraped dataset.

## 📁 Repository Structure
* `books_scraping_sql_pipeline.ipynb`: The main Jupyter Notebook containing the full ETL script, data cleaning logic, and SQL analysis.
* `books_collection.db`: The SQLite database generated by the pipeline.

## 🚀 How to Run the Code
1. Clone this repository to your local machine.
2. Ensure you have the required libraries installed: `pip install requests beautifulsoup4 pandas`.
3. Open the Jupyter Notebook and run the cells sequentially to execute the web scrape, build the database, and print the SQL insights.
